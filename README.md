# Space Exploration Quiz

## Overview
The Space Exploration Quiz is an interactive web-based quiz designed to test your knowledge about space exploration. It features a series of 10 questions, a progress bar to track your progress, and a score counter to keep track of your performance. The quiz provides colorful animated feedback for correct and incorrect answers, enhancing the user experience. At the end of the quiz, users are presented with a results screen that includes emoji reactions based on their score.

## Features
- 10 engaging questions about space exploration
- Progress bar to visualize quiz completion
- Score counter to display current score
- Animated feedback:
  - Green for correct answers
  - Red shake animation for incorrect answers
- Results screen with emoji reactions based on the final score
- Responsive design with a polished sans-serif font
- Supports light and dark modes via prefers-color-scheme

## How to Run the Quiz
1. Download or clone the repository to your local machine.
2. Navigate to the project directory.
3. Open the `index.html` file in your preferred web browser.
4. Enjoy the quiz and test your knowledge of space exploration!

## Additional Notes
- The quiz is designed to be simple and user-friendly, making it accessible to users of all ages.
- The project is built using only HTML, CSS, and JavaScript, with no external dependencies.
- Feel free to modify the questions or styles to personalize your quiz experience.
